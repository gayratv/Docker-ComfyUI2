git clone https://github.com/PrunaAI/pruna.git
cd pruna

Собираем sdist и wheel:
python -m build

Готовые артефакты появятся в ./dist/ (например, pruna-<версия>-py3-none-any.whl). Это стандартный способ для проектов с pyproject.toml. Если хотите только wheel, можно так:


python -m pip wheel . -w dist


Установка собранного wheel

python -m pip install ./dist/pruna-<версия>-py3-none-any.whl
